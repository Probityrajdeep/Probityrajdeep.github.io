# Rajdeep Mishra — Cybersecurity Portfolio

A responsive, static portfolio website focused on SOC operations, blue-team fundamentals, threat detection and vulnerability assessment.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Keep `styles.css`, `script.js`, and the `assets/` folder alongside `index.html`.

No framework, build step, package manager or backend is required.

## Publish with GitHub Pages
1. Create a public repository named `Probityrajdeep.github.io` under your GitHub account.
2. Upload all files and folders from this ZIP to the repository root.
3. In the repository, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. After GitHub Pages publishes the site, visit `https://Probityrajdeep.github.io`.

## Before publishing
- Check contact details and dates.
- Add screenshots and a short technical write-up for the SOC honeypot and phishing URL projects when you have them ready.
- Link dedicated project repositories once those repositories contain the corresponding source code, setup steps and evidence.
- The portfolio currently links only the public ESP32 Radar repository as a project repository. Other projects are presented as project summaries, not linked to repositories that have not been verified.

## Files
- `index.html` — site structure and portfolio content
- `styles.css` — responsive dark theme and layout
- `script.js` — mobile navigation, project filters, copy-email action and reveal animations
- `assets/Rajdeep_Mishra_Cybersecurity_Resume.pdf` — downloadable resume
